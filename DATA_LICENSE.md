# Data and imagery terms

Code in this repository is released under the MIT License. Compact tables
derived by this experiment may be reused under CC BY 4.0 with attribution.

The global FPV catalogue is a structured transcription of the supplementary
table to Nobre et al. (2024), DOI 10.1016/j.solener.2023.112244. Cite that
paper when using those records and consult the publisher's terms for the
source supplement. This repository does not redistribute the publisher PDF.

The simplified world boundaries used only for globe context come from
`johan/world.geo.json`, derived from Natural Earth public-domain data.
MapLibre GL JS 5.12.0 is vendored under its BSD-3-Clause license.

The live EO panel requests Sentinel-2 L2A catalogue metadata and a temporary
true-colour crop from Microsoft Planetary Computer at view time. The repository
does not persist those dynamically requested crops. The Blender `.blend` and
GLB contain derived catalogue coordinates and project-authored geometry, not
provider SAR or optical raster products.

Raw Sentinel-1 and NISAR imagery is deliberately not redistributed. Users must
retrieve it from its authoritative provider and comply with the applicable
Copernicus and NASA Earthdata terms. Site masks retain the terms of their
original sources and are not included in the public repository unless their
redistribution rights are verified.

The large per-trial tables are omitted from Git history because one file exceeds
GitHub's ordinary file limit. They are reproducibly generated by the notebook
and should be deposited as a versioned research release or Zenodo archive.
