# Results

The tracked figures are publication-resolution views of the pooled recovery
curves. The primary comparison is `harmonized_20m`; `matched_10m` is retained
as a limited-resolution sensitivity analysis.

The interactive 3D site comparison lives in [`../docs/`](../docs/). Its column
heights are symbolic encodings of MD95—not physical structures or array
footprints. Numerical source data are in
[`../data/derived/site_md_summary.csv`](../data/derived/site_md_summary.csv).
