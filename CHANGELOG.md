# Changelog

## 0.5.0 — 2026-10-05

- Rebuilt FPV Earth as an Artifact-Explorer-style research interface with a searchable 643-record catalogue, 3D country columns and mode-specific workspaces.
- Added on-demand nearest-date Sentinel-2 L2A catalogue lookup and true-colour crops through the public Planetary Computer APIs.
- Added an evidence animation for registered pre/post/change rasters and retained explicit detected/ambiguous/below-detection semantics.
- Added a reproducible Blender 3.6 WGS84 scene, 360-frame rotation rig, animated GLB and rendered preview.
- Embedded the distinction between documented localized change, below-detection outcomes and visually exaggerated synthetic motion in both the UI and Blender scene metadata.

## 0.4.0 — 2026-10-04

- Added a reproducible 643-record global FPV catalogue layer from the Nobre et al. survey.
- Added a self-contained 3D Earth interface with 517 geolocated installations, chronological playback and record inspection.
- Added the synthetic motion laboratory with exact tracked MD50/80/95 curves, optical footprints and the validated Tengeh replay.
- Added event-evidence mode for Yamakura and Omkareshwar with explicit claim boundaries.
- Vendored MapLibre and world boundaries so the globe works without runtime CDN dependencies.

## 0.3.0 — 2026-10-02

- Added an immersive MapLibre evidence atlas designed for GitHub Pages.
- Added ten browser-ready raster layers generated from tracked GeoTIFFs.
- Added georeferenced FPV, stable-control and damage-sector overlays.
- Added known-versus-recovered injection vectors and scene-level provenance.
- Replaced the decorative 3D result columns with scaled site MD95 symbols.

## 0.2.0 — 2026-10-02

- Rebuilt the GitHub Pages experience as a paper-style research narrative.
- Added the complete QGIS pilot trail and selected audit-size GeoTIFFs/QGIS projects.
- Added archived formative evidence from Omkareshwar, Yamakura and the NISAR screen.
- Added a real-raster synthetic injection diagram generated with the frozen engine.
- Added a full research report, QGIS workflow and primary-source references.
- Kept conclusions explicitly bounded by the small early-NISAR held-out sample.

## 0.1.0 — 2026-10-02

- Archived the acquisition-disjoint NISAR/Sentinel-1 benchmark.
- Added compact pooled and site-level observability tables.
- Added the interactive 3D MD95 explorer.
- Added a power audit, reproduction guide, citation metadata, and release tests.
